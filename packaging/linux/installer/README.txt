Glimpse for Linux
======================

To run Glimpse without installation, simply click the "Glimpse" file and run it as an executable.

To install or upgrade Glimpse, click the "Install.sh" file.
To uninstall Glimpse, click the "Uninstall.sh" file.

NOTE: By default, installation/uninstallation works interactively using kdialog & qdbus. If you do not have these installed, do not wish to install them, or otherwise wish to run using the native shell, pass "-s" as the first parameter, and they will output to the shell instead.
