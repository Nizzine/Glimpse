# Creating Plugins
Glimpse can be easily extended with custom plugins, both through official plugins, and through community creations.

Plugins are written in the [C#](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/overview) programming
language, and, therefore, are naturally cross-platform without the need to recompile for multiple platforms, while
remaining fast, bloat free, and easy to create.

### New to C#?
These docs expect a certain level of experience with C#. If you're new to programming, or just never used C#, you should
follow the [official C# tutorials](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/).
Fortunately, Glimpse's API is simple enough that you don't need much experience to write plugins.
